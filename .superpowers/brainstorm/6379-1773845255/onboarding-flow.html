User Flow

First visit (empty library):
→ Auto-redirect to /setup
→ Step 1: Navigate to Environment Wizard → complete → return to /setup
→ Step 2: Navigate to Detection Onboarding → complete → return to /setup
→ Step 3a: Navigate to SIEM Integration → connect → return to /setup
→ Step 3b: Fetch existing rules from connected SIEM
→ Step 4: Navigate to Action Plan (now with full context)
Returning user (some steps done):
→ Auto-detect: env profile exists ✓, detections > 0 ✓, no SIEM ✗
→ Show /setup with steps 1-2 pre-completed
→ Highlight step 3 as "next"
